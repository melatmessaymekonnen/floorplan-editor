# Floor Plan Editor
A web-based 2D floor plan editor where users can draw and edit room layouts in the browser.

**Status:** In progress 🚧**Demo:** https://floorplan-editor-azure.vercel.app/
![Floor Plan Editor](screenshots/editor-demo.png)

## Features
- [x] Draw walls with snap-to-grid and live length preview
- [x] Doors and windows placed on walls
- [x] Room labels and automatic wall dimensions (meters)
- [x] Select, move, resize and delete walls
- [x] Undo / redo
- [x] Pan and zoom
- [x] Save / open plans as JSON
- [x] Export as PNG
- [x] Demo apartment
- [ ] Furniture library
- [ ] Room area calculation
- [ ] Touch / mobile support
## Built with
React, TypeScript, Vite, HTML5 Canvas

## Run locally
```
npm install
npm run dev
```
