# Floor Plan Editor
A web-based 2D floor plan editor where users can draw and edit room layouts in the browser.

**Status:** In progress 🚧

## Features
- [x] Canvas drawing
- [ ] Snap to grid
- [ ] Undo / redo
- [ ] Save and load plans
- [ ] Export as PNG

## Built with
React, TypeScript, Vite, HTML5 Canvas

## Run locally
```
npm install
npm run dev

```
